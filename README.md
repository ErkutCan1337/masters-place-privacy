# Master's Place Kebab — Privacy Policy

Public privacy policy page for the mobile game **Master's Place Kebab** (`com.ustakebapci.game`),
published with GitHub Pages and used as the Privacy Policy URL on the App Store and Google Play.

- Page: https://erkutcan1337.github.io/masters-place-privacy/
